Dodge the Creeps

A small 2D game I'm making with Godot 4 while learning game development.

About the Game

In this game, you control a player and try to dodge the creeps coming toward you. The goal is to stay alive for as long as possible and get a higher score.

It's a simple game, but building it has helped me understand how different parts of a game work together.

Built With

- Godot 4
- GDScript

What I'm Learning

While making this game, I'm learning about:

- Player movement and input
- Collision detection
- Spawning enemies
- Timers and signals
- Score and game-over systems
- Connecting different scenes in Godot

How to Run

1. Download or clone this repository.
2. Open Godot 4.
3. Click Import and select the "project.godot" file.
4. Open the project and press F6 to run the current scene, or F5 to run the main project.

Current Progress

I'm still working on the game and fixing bugs as I learn. I'll keep improving it and adding features along the way.
