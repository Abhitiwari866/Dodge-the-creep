# Dodge-the-creep
🎮 Dodge the Creeps! Test your reflexes in Dodge the Creeps, an adrenaline-fueled 2D arcade survival game built with the Godot Engine!  Your goal is simple: survive as long as possible while dodging an ever-growing horde of relentless monsters. Every second in the arena demands quick thinking and sharp maneuvers—one touch, and it's game over!
